# ByteSpace New

A modern, responsive e-learning platform landing page built as part of the **Jr. Software Engineer (Frontend) assessment**.

The project is based on the provided ByteSpace design and focuses on creating a clean, responsive, and visually accurate learning platform experience.

## 🔗 Live Demo

**Live Website**:https://bytespace-new-topaz.vercel.app/ 

**GitHub Repository**:https://github.com/ssdevcmd/bytespace-new 
---

## ✨ Features

* Responsive landing page
* Modern e-learning platform UI
* Responsive navigation bar
* Hero section based on the provided design
* Course and learning-focused visual sections
* Creator/instructor section
* Interactive hover states
* Mobile-friendly layout
* Reusable React components
* Optimized layout for desktop, tablet, and mobile screens

### Bonus Features

* Login page
* Signup page

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd bytespace-new
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To run the production server:

```bash
npm start
```

## 🎨 Design

The UI was implemented based on the provided **ByteSpace New Figma design**.

The implementation focuses on:

* Visual consistency
* Typography
* Spacing
* Colors
* Responsive behavior
* Component reusability
* Desktop and mobile layouts

---

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

Tailwind CSS responsive utilities are used to adapt layouts and spacing across different screen sizes.

---

## 🧩 Component Approach

The landing page is divided into reusable components rather than keeping everything inside a single page.

Examples:

```text
Navbar
Hero
CareerGrowthSection
CoursesSection
CreatorSection
TestimonialsSection
Newsletter
Footer
```

This makes the codebase easier to maintain and extend.
